Have the agent **record what it's doing** as video. Playwriter streams JPEG frames with CDP `Page.startScreencast` and pipes them to `ffmpeg`. No permission prompt, no extension click, and the **recording survives page navigation**, also cross-site.

It works in every mode: extension, direct CDP (`PLAYWRITER_DIRECT`), [headless](/docs/headless), cloud browsers and remote control.

## Requirements

`ffmpeg` must be installed and on `PATH`.

```bash
# macOS
brew install ffmpeg

# Debian / Ubuntu
sudo apt install ffmpeg
```

## Start recording

`recording.start()` returns a **handle**. Keep it in `state` to use it in later execute calls:

```js
state.video = await recording.start({
  page: state.page,
  outputPath: '/absolute/path/to/recording.mp4',
  frameRate: 30,
})
```

## Navigate and interact

Recording continues across page navigations. No restart needed:

```js
await state.page.click('a')
await state.page.waitForLoadState('domcontentloaded')
await state.page.goBack()
// Still recording
```

Static pages are fine too. The last frame is **repeated** at a constant frame rate, so the video duration matches real time.

## Stop and save

```js
state.recordingResult = await state.video.stop()
// => { path, duration, size, executionTimestamps }
```

`duration` is the media duration in ms, `size` is the file size in bytes. Save the full result to `state` because `executionTimestamps` is needed for `createDemoVideo`.

## Options

| Parameter | Type | Default | Description |
|---|---|---|---|
| `page` | Page | required | Page to record. Change it later with `setPage()` |
| `outputPath` | string | required | Absolute output path. `.mp4`, `.mov`, `.mkv` or `.webm` |
| `clock` | `'real'` \| `'manual'` | `'real'` | `'manual'` freezes page time; see [Manual clock](#manual-clock) |
| `frameRate` | number | 30 | Frames per second, max 60 |
| `audio` | boolean | false | Record page audio (see [Audio](#audio)) |
| `maxSize` | number | 1920 | Longest output edge in pixels |
| `quality` | number | 90 | JPEG quality of captured frames, 0-100 |
| `aspectRatio` | object \| null | `{ width: 16, height: 9 }` | Shrink viewport to this ratio; `null` to skip |
| `maxDurationMs` | number | 15 min | Auto-stop safety limit; `0` to disable |

## Output format

The output size is the viewport in **device pixels** (viewport × `devicePixelRatio`), with the longest edge capped by `maxSize` and both dimensions rounded to even numbers.

| Extension | Video | Audio |
|---|---|---|
| `.mp4`, `.mov`, `.mkv` | H.264 | AAC |
| `.webm` | VP8 (realtime) | Opus |

H.264 uses a **hardware encoder** when ffmpeg has one (`h264_videotoolbox` on macOS, NVENC, QSV or AMF on Windows and Linux), else `libx264`. Any other extension throws.

On 120 Hz or 144 Hz displays Chrome sends more frames than needed, so the recorder asks for every Nth frame to save CPU.

## Audio

Pass `audio: true` to record **page audio**:

```js
await recording.start({
  page: state.page,
  outputPath: '/absolute/path/to/demo.mp4',
  audio: true,
})
```

Playwriter injects a Web Audio tap in the page. It captures `<audio>` and `<video>` elements (also DRM media) and AudioContexts that play to the speakers, then sends the PCM to ffmpeg.

Limitations:

- No audio from cross-origin (out-of-process) iframes
- An AudioContext graph wired **before** `recording.start` is missed
- The page can detect the patched audio APIs while recording

## Manual clock

With the default `clock: 'real'`, the video is wall-clock time: every second the agent spends thinking is in the video. Pass `clock: 'manual'` to **freeze page time** instead. Time moves only when you add frames, so agent latency never shows and animations play smoothly at any frame rate:

```js
state.video = await recording.start({ page: state.page, outputPath: '/abs/demo.mp4', clock: 'manual' })

await state.page.getByRole('button', { name: 'Open menu' }).click()
await state.video.wait(400)  // 400ms of page time = 12 frames at 30 fps

for (let y = 0; y < 600; y += 40) {
  await state.page.mouse.wheel(0, 40)
  await state.video.frame()  // one frame per wheel step
}

await state.video.stop()  // encode and give the page real time back
```

```
agent ── click ─────────────> page time frozen, nothing moves
agent ── video.wait(400) ───> advance 33ms → screenshot → advance 33ms → screenshot ...
agent thinks for 10s ───────> page time frozen, nothing recorded
agent ── video.stop() ──────> encode frames, resume real time
```

| Call | What it does |
|---|---|
| `video.frame()` | Moves page time by one frame (`1000 / frameRate` ms), then captures it |
| `video.wait(ms)` | Captures `ms` of page time |

Frozen: `Date`, `performance.now`, timers, `requestAnimationFrame`, CSS animations and transitions, and `element.animate()`. Input lands **instantly** between frames, so move the mouse in small steps across frames for a visible glide.

Limitations:

- `<video>` and `<audio>` playback, smooth scrolling, GIFs, workers and iframes still run in real time
- Timers that the page started **before** `recording.start` keep real time. Start the recording before `goto()` to control them all
- No `audio: true`. Use `video.wait(ms)`, not `waitForTimeout()`, to let the page move on
- After `stop()` the page keeps fake timers that follow real time until it reloads

## Record another tab

`setPage()` moves the recording to another tab. The output size stays the same; frames are scaled and padded to fit:

```js
state.other = await context.newPage()
await state.other.goto('https://example.com')
await state.video.setPage(state.other)
```

With `clock: 'manual'`, the old tab gets real time back and the new tab is frozen.

## Other recording commands

```js
state.video.isRecording  // false after stop, cancel, page close or max duration
state.video.page         // tab being recorded
await state.video.cancel()  // stop without saving
```

Several pages can record **at the same time**. Each `recording.start()` returns its own handle.

## Ghost cursor

The extension injects a **ghost cursor** overlay on every Playwriter-attached tab. It follows mouse actions automatically, making recordings look natural.

```js
// Change cursor style
await ghostCursor.show({ page: state.page, style: 'screenstudio' })
// Styles: 'minimal' (default), 'dot', 'screenstudio'

// Temporarily hide the cursor
await ghostCursor.hide({ page: state.page })
```

For best-looking recordings, use **locator-based interactions** (`locator.click()`, `state.page.mouse.move()`) instead of `goto()` to show realistic cursor motion.

## Demo video acceleration

After a `clock: 'real'` recording, use `createDemoVideo` to **speed up idle sections** (time between execute calls) while keeping interactions at normal speed. Requires `ffmpeg` and `ffprobe` installed. A `clock: 'manual'` recording has no idle sections, so it does not need this.

```js
// First, stop recording and save the result
state.recordingResult = await state.video.stop()

// Then in a SEPARATE execute call (with --timeout 120000):
const demoPath = await createDemoVideo({
  recordingPath: state.recordingResult.path,
  durationMs: state.recordingResult.duration,
  executionTimestamps: state.recordingResult.executionTimestamps,
  speed: 6,  // default 6x for idle sections
})
```

This can take **60-120+ seconds**. Always pass `--timeout 120000` or higher.

## Library usage

Record any Playwright page from your own Node.js code:

```ts
import { startRecording } from 'playwriter'

const rec = await startRecording({
  page,
  outputPath: './demo.mp4',
  audio: false,
  frameRate: 30,
})
await page.goto('https://example.com')
const { path, duration, size } = await rec.stop()
// or: await rec.cancel()
```

`startRecording({ clock: 'manual' })` gives the same `frame()`, `wait(ms)` and `setPage(page)` methods.

## Limitations

- **Ends with the page.** The recording is tied to the Playwright page and stops when the page closes or the session is reset.
- **Auto-stops after 15 minutes** by default. Override with `maxDurationMs`.
- **Viewport auto-resizes** to 16:9 (it only shrinks). Pass `aspectRatio: null` to keep the current size.
